# 注册／登录更新

已加入 Supabase Auth 手机短信与邮箱注册、登录、邮箱验证、密码重置和退出。手机号输入覆盖全球 245 个国家／地区代码，并标准化为 E.164；邮箱支持国际化域名。界面提供 21 种语言切换，会优先采用浏览器语言，选择结果保存在本机；尚未翻译的文本回退为英文。短信实际可达范围仍取决于配置的短信服务商、国家／地区法规和 Supabase 项目设置，不能仅凭号码选择器保证全球送达。配置步骤见 [认证配置](docs/注册认证配置.md)。

没有配置在线认证时，应用默认以本机游客模式启动，便于直接体验完整交互；可从顶部“账户入口”进入注册页，但不会发送验证码或创建账户。游客模式的发布、消息和交换只保存在当前浏览器，不会联系真实用户。前端现在支持在已登录且 API 地址已配置时连接后端 API；未配置服务仍使用本机演示。当前仓库没有已部署的生产 API、云数据库或图片服务，详见 [API 接入说明](docs/API接入说明.md)。

`releases/huanhuan-app-v0.2-web.zip` 是历史未含注册入口的发布包；本次源码更新后请配置认证环境变量，运行 `npm run package:app` 重新生成，勿直接分发旧包。

# 换换 APP · 闲置交换

## 可安装 APP（v0.2）

已加入 PWA 应用清单、桌面图标、独立窗口、离线缓存和安装入口。使用 `npm run package:app` 生成静态发布 ZIP，使用 `npm run preview` 在 4173 端口体验安装版。具体步骤见 [APP 安装说明](docs/APP安装说明.md)。这是可安装网页应用，不是 APK；手机安装和断网运行尚待实机验证。


React + Vite 的响应式中文交互原型。首页、分类搜索、收藏、物品详情、图片发布、消息、交换申请、双向交接确认与评价均可体验。

```sh
npm install
npm run dev
npm run build
npm test
```

开发预览监听 `0.0.0.0:5173`，允许 Arena 的 `.e2b.app` 预览域名。

## 体验

- “我的交换”预置一条收到的申请，可接受、确认交接，再通过明确标注的“模拟对方确认”体验完成流程。
- 物品详情点击“我想换”，选择自己的闲置发起申请。
- 本机演示模式的数据保存在当前浏览器 localStorage，个人设置可重置演示数据；后端模式仅在登录且配置 `VITE_API_BASE_URL` 后启用。
- 已接通个人资料、物品 CRUD/下架/恢复、收藏、交换、消息、举报与拉黑 API 流程；这只是可配置的客户端集成，尚无生产 API、真实图片上传、运营客服或物流。后端是否持久化取决于实际仓库配置。
- 示例城市、距离、用户和物品描述均为虚构数据。高价值物品是视觉示例，不代表首发品类开放决定。

## 测试

`npm test` 验证国际号码与邮箱处理、境内版默认配置、本机演示数据隔离、API client/repository 映射、Fastify API、PGlite PostgreSQL 兼容路径和交换状态机。PGlite 不是生产 PostgreSQL 部署或并发验收。
`npm run test:browser` 覆盖游客浏览、英语与 RTL 界面切换、个人资料编辑、本机物品编辑/下架/恢复、全球国家／地区号码列表、全球城市输入、物品详情、演示聊天、账户入口和移动端布局。需先启动 `npm run dev` 并安装 Chromium 所需系统共享库。当前沙盒缺少 Chromium 系统库 `libnspr4.so`、`libnss3.so` 和 `libnssutil3.so`，所以浏览器测试尚未执行；生产构建与单元测试已通过。
