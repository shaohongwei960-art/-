# 记法与命名约定

## 目录命名

`arrangements/<小写英文短名>/`，用连字符，不要空格和中文。
例：`example-canon-folk`、`moonlight-jazz-trio`。

## 和弦写法

| 写法 | 含义 |
| --- | --- |
| `C` | 大三和弦 |
| `Cm` | 小三和弦 |
| `C7` / `Cmaj7` / `Cm7` | 属七 / 大七 / 小七 |
| `Cm7b5` `Cdim7` `Caug` | 半减 / 减七 / 增三 |
| `Csus2` `Csus4` `Cadd9` | 挂留 / 加九 |
| `C/E` | 转位，斜线后是低音 |

代码里 `theory.chord("Cmaj7", octave=3)` 直接返回 MIDI 音高列表，写法与上表一致。

## 小节谱格式

一行四小节，竖线对齐，`%` 表示重复上一小节：

```
| C      | G/B    | Am7    | %      |
```

## 音高写法

科学音高记号，**C4 = 中央 C = MIDI 60**。
`theory.pitch("F#5")` → 78。注意：有些 DAW 把中央 C 记作 C3，导入时差一个八度属正常。

## 时间单位

代码里所有时间都以**拍**为单位（float），4/4 拍一小节 = 4.0。
`Track.note(beat, pitch, duration, velocity)` 的 `beat` 从 0 开始计，小节 N 的起点 = `(N-1) * 4.0`。

| 号 | 音色 | 号 | 音色 |
| --- | --- | --- | --- |
| 0 | 大钢琴 | 33 | 电贝斯（指弹） |
| 4 | 电钢琴 | 40 | 小提琴 |
| 24 | 尼龙弦吉他 | 48 | 弦乐合奏 |
| 25 | 钢弦木吉他 | 56 | 小号 |
| 27 | 电吉他（clean） | 73 | 长笛 |
