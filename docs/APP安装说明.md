# 换换 APP v0.2 · 安装与部署

## 这是什么

可安装到手机桌面的 PWA 网页应用，不是安卓 APK 或 iOS IPA。包含独立窗口、桌面图标、离线缓存和本机数据保存。没有真实后端、账户同步、审核或客服。

## 手机安装

先在手机上打开“换换 APP · 安装版”的独立 HTTPS 预览地址，不要在内嵌窗口中安装。

- Android：使用 Chrome，点击页面“安装到手机”；浏览器支持时有直接安装按钮，否则从浏览器菜单选择“安装应用”或“添加到主屏幕”。
- iPhone：使用 Safari，点击分享 → 添加到主屏幕 → 添加。需要时打开“作为网页 App 打开”。
- 桌面：Chrome / Edge 支持地址栏安装入口，具体取决于浏览器与系统。

首次联网打开后，等待离线资源就绪再断网。应用更新时会提示更新，建议先提交当前表单。预览地址仅适合测试，不是长期生产域名。

## 部署 ZIP

`releases/huanhuan-app-v0.2-web.zip` 是已编译静态发布包，不是手机安装包。
解压后将 `web/` 中所有文件部署到 HTTPS 网站根目录。必须保留 `sw.js`、`manifest.webmanifest` 和 `assets/` 路径。
建议 `sw.js` 与 `index.html` 使用 Cache-Control: no-cache；带哈希的 assets 可使用长期缓存。

```sh
npm ci
npm run build
npm run preview
node scripts/package-app.mjs
```

预览服务监听 0.0.0.0:4173；在非 localhost 域名安装需 HTTPS。禁止将开发服务器直接作为生产部署。

## 当前限制

- 这是有完整本机交互流程的体验版本，尚不是供多人真实交易的上线系统。
- 物品、消息、举报和评价仅保存在当前浏览器；普通浏览器与安装后的 APP 是否共享存储取决于系统，不承诺同步。
- 清除网站数据、浏览器数据或系统回收存储可能导致记录丢失；没有云备份。
- 自动离线资源包含示例图片和字体，约 5.6 MB，第一次加载需要联网。
- 素材授权说明见仓库 docs/图片来源.md，正式上线前需替换参考图片。
- 构建、PWA 文件检查和状态机测试已通过。受环境缺少浏览器共享库限制，尚未实际验证手机安装与断网运行。

真正发布 APK / App Store 应用还需要选择目标系统、移动端构建环境、签名和分发设置；真实多人使用还需要服务端、数据库、文件存储与安全审核。当前没有生成或伪装这些产物。
