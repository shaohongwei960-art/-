# 手机号／邮箱注册认证

## 已实现

配置 Supabase 后，应用启动时先检查认证会话；没有会话则进入注册／登录页。支持手机号短信验证码、邮箱密码注册与验证邮件、邮箱密码登录、邮箱找回密码、退出登录和会话恢复。手机号选择器覆盖 libphonenumber-js 数据库中的 245 个国家／地区，按 ISO 地区解析本地号码并转换为 E.164；也接受带 `+` 的完整国际号码。邮箱校验支持国际化域名（IDN），会将域名转换为 ASCII/Punycode 后提交。未配置在线认证时，应用默认进入本机游客演示，账户入口中的注册操作保持禁用，不发送验证码或创建账户。登录页也提供明确标注的本机演示入口。使用 Supabase Auth SDK，没有模拟 OTP 或本机密码注册。

界面语言选择器提供 21 种选项：简体中文、繁体中文、英语、西班牙语、法语、德语、葡萄牙语、阿拉伯语、印地语、孟加拉语、日语、韩语、俄语、印度尼西亚语、土耳其语、越南语、泰语、斯瓦希里语、乌尔都语、意大利语和菲律宾语。默认优先按浏览器语言选择，用户手动选择会保存在当前浏览器；仍未提供对应译文的文案回退为英语。

本机演示数据按认证 user.id 分开保存在 localStorage，避免正常切换账号时混用；这不是服务器权限隔离。若另行配置后端 API，业务数据由服务端仓库处理；本仓库没有配置生产 API，不能据此认为已经实现云同步。不要在共享设备上保存敏感演示数据。旧版匿名演示数据不迁移。详细配置见 [API 接入说明](API接入说明.md)。

## 配置步骤

1. 创建并管理自己的 Supabase 项目，复制 `.env.example` 为 `.env.local`。
2. 填入项目 HTTPS URL 和浏览器可用的 publishable/anon key；**绝不能填 service_role key**。Vite 环境变量会打包到浏览器。
3. 在 Auth 配置中开启邮箱注册和 **Confirm email**。设置密码最少 12 位；前后端规则应保持一致，开启适用的密码安全检查。
4. 配置受控的邮件发送服务（SMTP）及发件域名。默认邮件服务可能只能向授权测试邮箱发送邮件，不应直接用于公开注册。
5. 开启 Phone provider，配置覆盖目标国家／地区的短信服务商和费用限额；发送凭据仅放在服务提供商后台。前端可解析 245 个地区代码，不代表短信服务商都能向这些地区送达；上线前必须逐国验证号码格式、运营商路由、发送者 ID、当地法规、资费和 Supabase 项目限制。中国大陆号码需核验短信渠道覆盖、模板、签名及相应资质。
6. 本界面按 6 位短信验证码设计，服务端 OTP 设置也应为 6 位，并设置过期时间和重发频率。注册请求允许创建用户；登录请求不自动创建用户。
7. 设置 Site URL 为实际部署域名，并将准确的 HTTPS 回调根地址（如 `https://your-domain/`）添加到 Redirect URLs。只授权自己控制的域名，不使用任意域名通配。
8. 配置变更后重新构建部署。开发：`npm run dev`；安装版：`npm run build && npm run preview`。

邮箱验证和重置使用 PKCE；在发起请求的同一浏览器打开邮件链接。邮件跳转回根地址，由 SDK 处理登录状态。移动端邮件打开到其他浏览器可能失败，需要重新从该浏览器发起。

## 上线前必须补齐

- 在服务端设置 Auth 请求、邮件、短信和 IP 限流。页面 60 秒倒计时只是交互提示，不是安全限流。
- 公开注册前集成适用地区的验证码／人机校验（当前表单还没有 captcha token 集成）、防短信轰炸与费用告警。不要仅在后台强制开启 CAPTCHA 后就认为当前客户端已适配。
- 配置邮件验证，不能关闭确认后将未验证邮箱当作有效身份。
- 发布正式用户协议、运营主体、联系方式、隐私政策、地区与年龄要求、数据保存规则和账号删除流程。页面现有说明仅用于受控开发测试。
- 验证成功、错误验证码、过期验证码、重复注册、未验证邮箱、密码重置、退出、跨账号隔离和网络异常；在真实手机上测试。
- 将现有 Fastify API、JWT 验证、用户授权和服务端交换事务部署到经评估的环境，并以真实 PostgreSQL 验收并发、备份/恢复和权限隔离；接入受控图片上传。AuthGate 只是前端路由入口，不替代服务端鉴权。

## 当前验证范围

`npm test`：245 地区选择、国际号码 E.164 规范化、Unicode 数字、国际化邮箱域名、错误脱敏及交换状态机测试通过。
`npm run build`：认证 SDK、多语言界面和 PWA 构建通过。
`npm run test:browser`：覆盖游客模式、英语及 RTL 界面切换、个人资料编辑、本机物品编辑/下架/恢复、245 个国家／地区号码列表、全球城市输入、详情与演示聊天；先运行 `npm run dev`，并安装 Chromium 系统共享库。

没有配置在线认证项目，未发送任何真实短信/邮件，尚未进行端到端真实账户验证。未配置时按钮禁用且显示明确提示。不得把配置完成前的版本称为已开放注册。
