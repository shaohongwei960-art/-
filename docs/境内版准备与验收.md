# 境内版准备与验收

**目标范围：** 中国大陆优先；免费实物互换；后续再启用海外区域。本文是工程准备清单，不是法律意见，也不代表已经备案或获批。

## 当前代码准备

- 使用 `npm run dev:mainland` 本地预览，或用 `npm run build:mainland` 构建境内默认版本；默认简体中文和 `+86`，用户仍可改用其他语言和国家／地区。
- 可复制 `.env.mainland.example` 为 `.env.mainland`，后续填入选定境内后端的公开配置。真实凭证不得提交到 Git 或粘贴到聊天中。
- **构建模式只设置界面默认值，不会自动把数据库、认证、短信、图片或数据部署到中国大陆。** `authClient.js` 目前使用 Supabase JS 客户端。启用之前，必须选择并核实境内服务端点、数据存储地、短信/邮件路由及个人信息处理方式；不得将境外项目地址误当成境内部署。
- 本机演示模式的物品、收藏、交换、消息、举报和评价保存在浏览器 `localStorage`，无法多用户同步。前端现可在登录并设置 `VITE_API_BASE_URL` 后调用 Fastify `/api/v1`，仓库含内存测试实现及 PostgreSQL repository；尚未部署生产服务，也没有完成真实 PostgreSQL/并发/备份验收。演示持久化仍隔离在 `src/localDemoRepository.mjs`。接入步骤见 [API 接入说明](API接入说明.md)。

## 备案/许可办理准备

以下事项的适用性和先后顺序，应由公司的接入云服务商、备案服务人员及熟悉相关法规的顾问按最终运营方式核实：

1. **核对主体与域名。** 确认域名实名主体、申请备案主体、网站/应用运营主体和云账号主体关系符合所选服务商要求；准备该服务商要求的企业材料和负责人核验。
2. **选择境内接入和部署服务。** 选择能为该主体和业务办理相应手续的境内云服务商及地域。先确认备案接入要求、服务器/云资源要求、域名要求及服务端口和证书方案；再确定生产部署。
3. **网站备案。** 如提供境内网站服务，按接入服务商流程准备并提交适用的 ICP 备案资料；在获准前不要把未备案的生产网站公开提供境内互联网信息服务。备案类型以主管部门/接入商核验为准。
4. **移动应用手续。** iOS/Android 境内分发前，向接入服务商、应用商店和主管部门核实该应用所需的应用备案、商店材料和版本信息；本仓库目前只有 PWA/网页代码，不是可上架的 APK/IPA。
5. **确认是否还需许可或其他手续。** 当前规划为免费实物交换、不代收款、不收佣金；但“免费”本身不能替代业务分类判断。是否涉及经营性电信业务、电子商务平台义务或其他许可，要按具体功能、收费、广告、平台角色及主管部门口径确认。网站公安联网备案等后续事项也应向接入商/属地主管部门核实。
6. **准备运营规则。** 上线前需要正式的用户协议、隐私政策、个人信息处理清单与保存期限、账号注销/删除机制、举报申诉渠道、违禁物品规则、人工审核及应急处理流程；需面向未成年人时另行评估年龄和监护人要求。

## 工程验收门槛

- **后端与权限：** 仓库已有 Fastify API、JWT 验证、用户授权和服务端交换事务实现，前端可连接 `/api/v1`；尚未选定/部署大陆数据库、认证、图片存储及接入服务。生产验收仍须验证真实 PostgreSQL 并发、数据隔离、备份恢复及图片上传，不能以 PGlite 测试代替。
- **境内账号服务：** 邮箱验证、密码重置、短信 OTP、供应商覆盖与费用限额、服务端限流、人机校验、重复注册/轰炸防护和告警均需实际配置并端到端测试。前端区号列表不代表短信可达。
- **平台治理：** 发布内容审核、禁售/危险品规则、举报工单、封禁与申诉、管理后台、审计日志和删除流程可实际工作。
- **原生客户端：** 完成 Android 和 iOS 构建、签名、邮件/短信回跳、图片选择、推送与弱网测试，并用真机验证；当前运行环境为 Linux，无 Android SDK/Java 或 Xcode，不能在此环境完成真机或 iOS 构建验收。
- **测试：** 单元测试、浏览器 E2E、RLS/权限测试、网络失败测试、备份恢复测试、真实服务沙箱注册测试和商店预审均需通过。当前 `npm test` 和 `npm run build` 只覆盖本机原型，不等于以上生产验收。

## 本次可复现命令

```sh
cp .env.mainland.example .env.mainland
npm ci
npm test
npm run build:mainland
npm run dev:mainland
npm run test:browser
```

浏览器测试要求开发服务器运行，并要求 Chromium 系统库齐全。本工作环境缺少 Chromium 共享库 `libnspr4.so`、`libnss3.so` 和 `libnssutil3.so`，所以 E2E 尚未实际运行。境内生产服务的凭证、备案材料和商店账号须在公司/服务商自己的安全控制台准备，不能由前端构建自动生成。
